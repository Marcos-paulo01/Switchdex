# Switchdex

Switchdex é um aplicativo homebrew para Nintendo Switch.

## Funcionalidades
- Banco de Dados da Pokedex: Navegue e visualize informacoes sobre os Pokemon.
- Montagem de Saves: Interface para interagir com arquivos de save de Pokemon diretamente no console.
- Interface de Usuario: Interface customizada construida para o Nintendo Switch.

## Estrutura
- include/: Arquivos de cabecalho (Header) em C++.
- source/: Arquivos de codigo-fonte em C++ (aplicativo principal, interface, banco de dados, motor de montagem).

## Compilacao
Para compilar este projeto, voce precisara do devkitPro com a toolchain devkitA64 e a biblioteca libnx instalados.
Execute `make` no diretorio raiz para compilar o arquivo `.nro`.
